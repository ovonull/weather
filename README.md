# 天气查询插件（cn.ucbk.weather）

群聊或私聊发「天气 北京」就能查实时天气和未来几天预报，数据来自 [Open-Meteo](https://open-meteo.com/)，**不需要申请 API Key**。

## 能力与出网

| 项 | 内容 |
| --- | --- |
| 能力 | `msg.send`（中风险）、`http.outbound`（**高风险**） |
| 出网域名 | `geocoding-api.open-meteo.com`（城市名解析）、`api.open-meteo.com`（天气数据） |
| 依赖 | 无第三方库，只用宿主 SDK 与标准库 |

`http.outbound` 是高风控能力，**审核时必须由管理员在面板上单独勾选**才会写入「已批准能力」；漏勾时插件能装，但一发「天气」就会回「未获批访问外网」。

## 打包与安装

```bash
python plugins/pack.py weather
# 生成 plugins/dist/cn.ucbk.weather-1.1.0.zip
```

1. 插件市场 → 提交压缩包，上传上面的 zip；
2. 插件审核 → 审核通过（记得勾选 `http.outbound`）→ 上架；
3. 插件市场 → 安装，勾选生效机器人，填好默认城市后**手动开启**（安装后默认停用）。

> 版本号说明：`1.0.0` 在插件市场里已经占用过，这份重写版从 `1.1.0` 开始；配置项的 key 与旧版完全一致，升级时同名配置会保留。

## 支持的写法

| 输入 | 结果 |
| --- | --- |
| `天气 上海` | 查上海 |
| `天气` | 查配置里的默认城市，没配就回用法提示 |
| `杭州天气` | 触发词在结尾也认 |
| `今天北京天气怎么样` | 自动剥掉「今天」「怎么样」这类词，查北京 |
| `天气 火星基地` | 找不到城市，回一条换写法的提示 |

多个触发词用英文逗号分隔，例如 `天气,查天气,weather`，匹配时长的优先（`天气查询` 不会先命中 `天气`）。

## 配置项

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 触发词 | 天气 | 英文逗号分隔，最多 10 个 |
| 默认城市 | 空 | 只发触发词时查这个城市；留空就必须带上城市名 |
| 预报天数 | 3 | **0 或留空取默认 3 天；-1 表示只显示实时天气**，最多 7 天 |
| 温度单位 | 摄氏度 | 选华氏度时直接让接口返回 °F |
| 生效范围 | 群聊与私聊 | 只想在群里用就选「仅群聊」 |
| 同一会话回复冷却 | 20 秒 | 冷却期内重复查同一个城市会被忽略；0 表示不冷却 |

## 一次查询的流程

1. 从消息里取出纯文本（只拼接 `text` 段，忽略图片、表情）；
2. 用触发词判断是不是查天气，并把城市名切出来；
3. `geocoding-api.open-meteo.com/v1/search` 把城市名换成经纬度，取第一条结果；
4. `api.open-meteo.com/v1/forecast` 取实时天气与逐日预报（`timezone=auto`，按城市当地时区）；
5. 拼成纯文本回复，天气代码按 WMO 编码翻成中文。

回复长这样：

```text
北京（北京市） 实时天气
晴间多云 24℃
体感 26℃ · 湿度 48% · 风 12 km/h

未来 3 天
10-18 周六 晴 26℃/16℃ 降水 10%
10-19 周日 多云 25℃/15℃ 降水 20%
10-20 周一 小雨 22℃/14℃ 降水 60%
```

## 约定

- 出网一律走 `host.http_request`，域名受清单白名单约束，换 API 必须同步改 `allowed_domains`；
- 任何失败都回中文提示，不向宿主抛裸异常，避免整条事件判定为失败；
- 不直接调用 OneBot，发消息一律通过 host 完成；
- 冷却状态只存在内存里，插件进程重启后清空。
