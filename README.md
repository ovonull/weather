# 天气查询插件（cn.ucbk.weather）

把实时天气与未来几天预报交给 AI 回答，数据来自 [Open-Meteo](https://open-meteo.com/)，**不需要申请 API Key**。

插件自己**不听消息、不发消息**：它只声明一个 AI 工具 `weather_query` 和一组触发词，宿主在消息命中触发词时强制这一轮交给 AI，并点名调用这个工具。

## 能力与出网

| 项 | 内容 |
| --- | --- |
| 能力 | `http.outbound`（**高风险**，审核时需管理员单独勾选） |
| 出网域名 | `geocoding-api.open-meteo.com`（城市名解析）、`api.open-meteo.com`（天气数据） |
| 依赖 | 无第三方库，只用宿主 SDK 与标准库 |

## AI 工具

| 项 | 内容 |
| --- | --- |
| 工具名 | `weather_query`（模型看到的是带前缀的完整名，插件内注册用原名） |
| 能力码 | `plugin.tool`（**机器人 AI 配置**里勾选，不是插件清单里的 capabilities） |
| 入参 | `city`（必填，城市名）、`days`（可选，预报天数，-1 只显示实时） |
| 返回 | 中文天气报告文本，模型自己组织回复 |
| 触发词 | `天气`、`气温`、`下雨`、`带伞`、`降水`（清单里的 `keywords`） |
| 超时 | 15 秒 |
| 结果上限 | 3000 字符 |

**启用步骤**：安装并启用插件后，在 机器人管理 → AI 配置 → 智能体 里勾选「插件工具」。工具清单随插件启停实时变化。

> 触发词命中时，宿主会绕过接话评分直接进 AI，并禁止模型用联网搜索代替——所以「合肥 天气」这种问法一定会走到这个工具，不会退化成网页搜索。

## 打包与安装

```bash
python plugins/pack.py weather
# 生成 plugins/dist/cn.ucbk.weather-1.2.2.zip
```

1. 插件市场 → 提交压缩包，上传上面的 zip；
2. 插件审核 → 审核通过（记得勾选 `http.outbound`）→ 上架；
3. 插件市场 → 安装，勾选生效机器人，填好默认城市后**手动开启**（安装后默认停用）。

> 版本号说明：配置项的 key 与旧版一致，升级时同名配置会保留。

## 支持的问法

| 输入 | 结果 |
| --- | --- |
| `合肥 天气` | 宿主命中触发词 → AI 调 `weather_query` → 回答 |
| `明天要带伞吗` | 命中「带伞」→ AI 调工具（没说城市时用配置的默认城市） |
| `上海气温多少` | 命中「气温」→ 查上海 |
| `火星基地天气` | 工具返回「没有找到这个城市」，AI 自己换说法 |
| 没提天气的闲聊 | 不触发，插件不参与 |

## 一次查询的流程

1. 消息命中 `keywords` 里的词 → 宿主把这一轮强制交给 AI，并点名 `weather_query`；
2. 模型带上 `city`（和可选 `days`）调用工具；
3. `geocoding-api.open-meteo.com/v1/search` 把城市名换成经纬度，取第一条结果；
4. `api.open-meteo.com/v1/forecast` 取实时天气与逐日预报（`timezone=auto`，按城市当地时区）；
5. 拼成纯文本返回给模型，由模型组织成一句人话。

报告长这样（模型通常会压缩成一两句）：

```text
北京（北京市） 实时天气
晴间多云 24℃
体感 26℃ · 湿度 48% · 风 12 km/h

未来 3 天
10-18 周六 晴 26℃/16℃ 降水 10%
10-19 周日 多云 25℃/15℃ 降水 20%
10-20 周一 小雨 22℃/14℃ 降水 60%
```

## 配置项

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| 默认城市 | 空 | 用户没说城市时查这个；留空则模型会先反问城市 |
| 预报天数 | 3 | **0 或留空取默认 3 天；-1 表示只显示实时天气**，最多 7 天 |
| 温度单位 | 摄氏度 | 选华氏度时直接让接口返回 °F |

## 约定

- 出网一律走 `host.http_request`，域名受清单白名单约束，换 API 必须同步改 `allowed_domains`；
- 工具处理函数不抛裸异常，失败返回可读文本，让模型知道发生了什么；
- 不直接调用 OneBot，插件没有任何发送能力；
- 没有开启 AI 回复的机器人不会触发这个插件——这是设计，不是 bug。
